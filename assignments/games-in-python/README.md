
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Construir o clássico jogo de adivinhar palavras usando strings, loops, condicionais, entrada de dados do usuário e seleção aleatória em Python.

## 📝 Tarefas

### 🛠️ Implementar o jogo da Forca

#### Descrição

Crie um jogo da Forca em que o jogador adivinhe letras para revelar uma palavra oculta antes de esgotar as tentativas.

#### Requisitos

O programa concluído deve:

- Selecionar uma palavra aleatoriamente de uma lista predefinida.
- Aceitar palpites de letras e mostrar o progresso atual no formato `_ _ _`.
- Rastrear o número de tentativas incorretas restantes.
- Encerrar quando a palavra for adivinhada ou quando as tentativas se esgotarem.
- Exibir uma mensagem de vitória ou derrota ao final do jogo.
