# 📘 Activity: Building REST APIs with FastAPI

## 🎯 Objective

Build a small REST API with FastAPI to manage a collection of books, practice route definitions, request validation, and JSON responses.

## 📝 Tasks

### 🛠️ Create the FastAPI app

#### Description
Set up a FastAPI application with a root endpoint and a basic in-memory data store for books.

#### Requirements
The completed program must:

- Create a FastAPI app instance.
- Add a root endpoint that returns a welcome message.
- Store a few sample books in memory.
- Return JSON responses from the API.

### 🛠️ List and create books

#### Description
Implement endpoints to list all books and add a new one.

#### Requirements
The completed program must:

- Add a GET endpoint to return every book in the collection.
- Add a POST endpoint to create a new book.
- Validate input data with a Pydantic model.
- Return the newly created book as JSON.

### 🛠️ Read, update, and delete a book

#### Description
Extend the API with endpoints for individual book operations.

#### Requirements
The completed program must:

- Add a GET endpoint for a single book by ID.
- Add a PUT endpoint to update an existing book.
- Add a DELETE endpoint to remove a book.
- Return a 404 error when a requested book does not exist.
- Keep the API responses consistent and easy to read.

### 🛠️ Improve the API experience

#### Description
Add better validation and response structure to make the API more realistic.

#### Requirements
The completed program must:

- Use a clear response model for book data.
- Validate required fields such as title and author.
- Include consistent status codes for success and not-found cases.
- Add a brief description in the API docs generated by FastAPI.
